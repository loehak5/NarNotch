Kebijakan Privasi NarNotch

Terakhir diperbarui: 2 November 2026

1. Data yang Kami Kumpulkan

NarNotch adalah aplikasi desktop Windows mandiri. Saat Anda menghubungkan akun Google Anda, NarNotch hanya meminta izin akses baca (read-only) untuk Google Calendar Anda.

2. Penggunaan Data Kalender

Data jadwal agenda kalender Anda hanya diambil untuk ditampilkan secara langsung pada antarmuka widget Notch di komputer Anda.

3. Penyimpanan Data

Semua data agenda, jadwal, dan token autentikasi disimpan secara lokal dan aman di perangkat komputer Anda sendiri. Kami TIDAK pernah mengirimkan atau menjual data kalender Anda ke server pihak ketiga mana pun.

4. Kepatuhan Kebijakan Pengguna Google API

Penggunaan dan transfer informasi yang diterima dari Google API oleh NarNotch ke aplikasi lain akan mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

5. Kontak

Jika Anda memiliki pertanyaan tentang kebijakan privasi ini, Anda dapat menghubungi kami melalui repositori proyek ini.
