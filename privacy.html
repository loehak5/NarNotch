Kebijakan Privasi NarNotch

Terakhir diperbarui: 2 November 2026

1. Ikhtisar Aplikasi

NarNotch adalah aplikasi desktop independen untuk sistem operasi Microsoft Windows 10 & 11. NarNotch dirancang untuk memberikan akses cepat terhadap utilitas media, telemetri sistem, kalender agenda, dan alat produktivitas melalui antarmuka Dynamic Island.

2. Data yang Dikumpulkan & Akses Akun Google

NarNotch mengutamakan privasi pengguna secara ketat:

  • Akses Google Calendar: NarNotch hanya meminta izin baca (read-only) terhadap agenda kalender pengguna (scope: https://www.googleapis.com/auth/calendar.readonly) untuk menampilkan jadwal harian Anda pada antarmuka widget Notch.
  • Data Lokal: Semua token otentikasi OAuth 2.0 dan data jadwal kalender disimpan secara terenkripsi dan eksklusif di perangkat komputer lokal Anda.
  • Tidak Ada Pelacakan: NarNotch tidak mengumpulkan identitas pribadi, riwayat penjelajahan, maupun data telemetri penggunaan ke server pihak ketiga.

3. Penggunaan & Pembagian Data

Kami TIDAK PERNAH menjual, menyewakan, membagikan, atau memindahkan data akun atau jadwal kalender Google Anda kepada pihak luar, pengiklan, atau server eksternal mana pun. Pemrosesan data terjadi 100% secara lokal pada memori komputer Anda.

4. Kepatuhan Kebijakan Data Pengguna Google API

Penggunaan dan transfer informasi kalender yang diterima dari Google API oleh NarNotch ke aplikasi lain akan mematuhi sepenuhnya ketentuan Google API Services User Data Policy, termasuk persyaratan Limited Use (Penggunaan Terbatas).

5. Penghapusan Akses & Data

Pengguna dapat memutuskan koneksi akun Google kapan saja melalui menu pengaturan NarNotch atau melalui halaman Google Account Permissions. Saat diputuskan, seluruh token otentikasi lokal akan segera dihapus dari komputer Anda.

6. Hubungi Kami

Jika Anda memiliki pertanyaan mengenai kebijakan privasi ini atau implementasi keamanan pada aplikasi NarNotch, Anda dapat menghubungi kami melalui repositori resmi di GitHub: https://github.com/loehak5/NarNotch.
